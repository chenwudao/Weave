# Literature discovery and evidence

Resolve a DOI or arXiv ID with paper_lookup. For a title or topic, use paper_search with includeStatus=true. Use Crossref and OpenAlex. Add arXiv for recent preprints or Europe PMC for biomedical literature when relevant. Record the search queries, which providers responded, and the inclusion criteria.

Use paper_neighbors when the assignment calls for citation tracing. For a small literature sample, verify the first suitable primary source and publish its title, locator, finding and named URL in a canvas draft before opening the next paper. Stop at the assigned count. Follow promising works to their primary text. Call paper_read on the registered PDF by id or the specific version of an open arXiv paper by arxivId. Keep the source and page locator for each claim. Metadata-only findings remain pending verification.

Deliver a source-linked evidence table or research brief suited to the Bot’s responsibility. When the task calls for durable evidence and project permissions allow it, propose atomic claims with evidence_add using the actual source and locator. Include the resulting evidence IDs in the deliverable. Report contradictory findings, unreadable pages and missing coverage.

In a library, use category for the collection and cite the original in sources. On a timeline, supply the actual publication or event date when known. Use relatedIds for notes that compare or complement each other, and parentId for a note that expands an existing card.
