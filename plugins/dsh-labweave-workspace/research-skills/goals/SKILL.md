# Research goals and acceptance

Define the intended research outcome, its success criteria and the evidence needed to accept it. Read current goals and explicit dependencies before revisions. Separate prerequisites from parallel work. Represent progress using actual deliveries and leave incomplete prerequisites visible. Set a measurable completion condition for proposed goals.

On a checklist, group by the project's actual categories or priorities and include known due dates. On a path, link true prerequisites with dependsOn and use parentId only for a subgoal. On a bus, connect shared prerequisites to the goal groups they actually feed.
