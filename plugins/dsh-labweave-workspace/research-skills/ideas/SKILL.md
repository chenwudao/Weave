# Hypotheses and minimum validation

Start with a concrete observation, articulate a falsifiable hypothesis, list a plausible competing explanation and define the smallest test that distinguishes them. Check existing evidence and retrieve literature when relevant. Record success and failure criteria before evaluation. Label proposals, expected outcomes and measured outcomes explicitly.

Use parentId to connect an alternative to the question or observation it branches from. On a reasoning layout, use dependsOn when a later step requires an earlier result. In a star, use relatedIds for alternatives that are meaningfully comparable around the central question.
